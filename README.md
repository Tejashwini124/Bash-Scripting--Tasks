# DevOps Daily Tasks

## 1. Bash Scripting Tasks
1. Check whether a directory exists.
2. Create multiple files.
3. Take a backup of a directory.
4. Install Nginx on an Amazon Linux EC2 server.
5. Install Apache Tomcat on an Amazon Linux EC2 server.
6. Check whether Nginx is running and start it if stopped.
7. Create a calculator using Bash.
8. Check whether a directory exists and create it if missing.
9. Delete the last three lines of a file.
10. Monitor CPU usage and send an email if usage exceeds 80%.
11. Monitor disk usage and send an email if usage exceeds 80%.
12. Monitor memory usage and send an email if usage exceeds 80%.
## 2. Crontab Tasks
1. Execute a task on April 5 at midnight.
2. Execute a task on January 5, June 5, and November 5, if the day is Thursday.
3. Execute a task at minutes 5 and 27 during hours 9, 10, and 11 every day.
4. Execute a task at 9:34 AM on August 15.
5. Execute a task every midnight.
6. Execute a task every Saturday at 11:59 PM.
7. Execute a task after every reboot.
## 3. Environment
Amazon Linux EC2
## 4. Objective
Practice Bash scripting, Linux administration, system monitoring, and Cron scheduling.
